تحديث تصميم Aytroun Grand SuperMarket

ارفع محتويات هذا المجلد إلى جذر GitHub Repository واستبدل الملفات القديمة.
أهم الملفات المعدّلة:
- index.html: تصميم المتجر، شاشة الافتتاح، الشريط الإعلاني، واجهة المنتجات والتصنيفات والتنقل السفلي.
- manifest.webmanifest: اسم التطبيق SuperMarket والاسم الكامل Aytroun Grand SuperMarket.
- sw.js: تحديث إصدار التخزين المؤقت لضمان وصول التصميم الجديد.

لم يتم تعديل Cloudflare Worker أو قاعدة D1 أو ملفات Admin أو إعدادات الاستيراد.
لم يتم تغيير بيانات المنتجات أو الطلبات أو الصور.
بعد النشر افتح الموقع واعمل Ctrl+F5 على الكمبيوتر، وعلى الهاتف أغلق التطبيق وافتحه مجدداً بعد تحديثه.
