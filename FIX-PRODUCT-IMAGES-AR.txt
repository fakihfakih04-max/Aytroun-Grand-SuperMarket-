إصلاح صور المنتجات:
- تم تضمين مجلد products/ من ملف products.zip.
- الواجهة تتعامل مع image المخزّن كـ Data URL أو رابط أو اسم ملف/مسار داخل products/.
- Worker يقرأ image حسب Product ID من D1 بدون شروط التوفر/الإظهار، مع Cache للصور.
النشر:
1) ارفع كل محتويات هذا المجلد إلى GitHub واستبدل الملفات القديمة.
2) انشر Cloudflare/worker.js على Worker الحالي.
3) لا تنفذ أي SQL أو Migration.
مهم: أسماء الصور داخل الأرشيف عشوائية. سيظهر الملف إذا كانت قيمة image في D1 تحمل اسم الملف أو مساره الصحيح، أو إذا كانت صورة Data URL محفوظة. إذا كان حقل image فارغاً أو لا يحتوي مرجعاً للصورة، يلزم ربط الصورة بمعرّف المنتج من بيانات الاستيراد؛ لا يمكن تخمين الربط من أسماء الملفات وحدها.
