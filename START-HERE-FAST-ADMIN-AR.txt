تحديث سريع للأدمن والباركود

1) ارفع admin.html من هذا المجلد إلى GitHub مكان الملف القديم.
2) انشر Cloudflare/worker.js على Cloudflare Worker.
3) افتح Cloudflare D1 Console ونفّذ Cloudflare/FAST-BARCODE-INDEXES.sql مرة واحدة.
4) افتح الأدمن واعمل Ctrl+F5.

النتيجة:
- الأدمن يجلب 100 منتج فقط في كل صفحة بدلاً من تحميل كل المنتجات دفعة واحدة.
- أزرار Previous/Next للتنقل.
- البحث النصي يبحث في قاعدة البيانات كلها، وليس الصفحة الحالية فقط.
- Scan / إدخال الباركود يستخدم مسار البحث المباشر الموجود في Worker ويبحث في كل المنتجات.
- البحث بالباركود يفتح المنتج للتعديل حتى لو لم يكن ضمن الصفحة الحالية.

مهم: لا ترفع ملفات index.html أو الصور أو بقية المشروع لهذا الإصلاح؛ فقط admin.html إلى GitHub وworker.js إلى Cloudflare، ثم SQL مرة واحدة. خذ نسخة احتياطية من الملفات الحالية قبل الاستبدال.
