AYTROUN GRAND SUPERMARKET - SETUP

الهدف الحالي: تشغيل لوحة Admin وتجربة إضافة منتج يدوي قبل استيراد SFF.

1) حدّث قاعدة D1 الموجودة مرة واحدة فقط:
   افتح Cloudflare > D1 > aytroun-db > Console
   انسخ محتوى Cloudflare/migrate-existing-d1.sql ونفّذه.
   لا تعِد تشغيله إذا ظهرت رسالة أن الأعمدة موجودة مسبقاً.

2) حدّث Worker:
   Cloudflare > Workers & Pages > aytroun-api > Edit code
   استبدل worker.js بمحتوى Cloudflare/worker.js ثم Deploy.
   لا تحذف Bindings أو Secrets: DB, ADMIN_PASSWORD, JWT_SECRET.
   لا حاجة إلى R2.

3) حدّث GitHub Pages:
   ارفع واستبدل الملفات من جذر المشروع بهذه النسخة، ثم Commit changes.
   تأكد أن index.html وadmin.html وconfig.js في جذر المستودع.

4) افتح لوحة الإدارة:
   https://fakihfakih04-max.github.io/Aytroun-Grand-SuperMarket-/admin.html
   سجّل الدخول بكلمة ADMIN_PASSWORD التي خزنتها كـ Secret في Cloudflare.

5) اختبر منتجاً يدوياً:
   - Product ID: TEST-001
   - Name: Test Product
   - Category: Beverages
   - Retail PC/PAC/BOX: أدخل أسعاراً تجريبية فقط
   - Pieces per PAC/BOX: أدخل أرقاماً تجريبية
   - Stock quantity: 5
   - Availability: Available
   - Description: Manual test item
   - اختر صورة صغيرة ثم Save Product.
   - افتح واجهة المتجر الرئيسية وتأكد من ظهور المنتج والصورة والوصف والأسعار وحالة Available.
   - جرّب تعديل المنتج ثم حذفه بعد الاختبار.

ملاحظات مهمة:
- الكمية الفعلية ظاهرة في Admin فقط؛ لا تظهر للزبائن.
- لا توجد أسعار تكلفة أو جملة في كتالوج الزبون.
- صور المنتجات واللوغو مضغوطة ومخزنة داخل D1، لذلك لا تحتاج R2 أو بطاقة.
- لا تربط هذا المشروع بقاعدة SFF مباشرة؛ الاستيراد سيكون من Backup/Export فقط.
- لا تشغّل SQL migration أكثر من مرة.
