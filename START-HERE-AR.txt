مشروع تعاونية عيترون الكبرى

النسخة الحالية لا تحتاج R2 ولا بطاقة دفع لتخزين الصور:
- صور المنتجات واللوغو يتم ضغطها داخل المتصفح ثم حفظها في D1.
- اختر صوراً معقولة الحجم؛ لوحة الإدارة ترفض الصورة إذا تجاوزت 500KB بعد الضغط.
- قاعدة البيانات: aytroun-db
- Worker: aytroun-api
- D1 binding: DB
- أسرار Worker: ADMIN_PASSWORD و JWT_SECRET

لتحديث الملفات:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub على الفرع main واستبدل الملفات القديمة.
2) في Cloudflare افتح Workers & Pages > aytroun-api > Edit code.
3) استبدل محتوى worker.js بمحتوى Cloudflare/worker.js الموجود في هذا ZIP ثم اضغط Deploy.
4) لا تنشئ R2 ولا تضف IMAGES binding.
5) لا تحذف D1 binding DB ولا Secrets الموجودة.
6) افتح رابط GitHub Pages ثم أضف /admin.html لتسجيل الدخول.

الميزات:
- إضافة وتعديل وحذف المنتجات.
- أسعار التجزئة PC وPAC وBOX وعدد الحبات في الباك والصندوق.
- صور المنتجات واللوغو محفوظة ضمن D1 بعد ضغطها.
- تعديل اسم المحل ورقم واتساب واللغة والعنوان.
- تحديد رسوم التوصيل لكل منطقة.
- مشاهدة الطلبات وتغيير حالتها.
- Backup/Restore لبيانات المنتجات والإعدادات والمناطق والصور.

تنبيهات:
- لا تضع كلمات السر داخل GitHub أو ملفات JavaScript.
- لا يوجد اتصال بقاعدة SFF الحية ولا تعديل عليها.
- مستورد SFF الحقيقي يحتاج نسخة Backup/Export فعلية لفحص بنيتها.
- إرسال الطلب عبر WhatsApp يفتح رسالة جاهزة والزبون يضغط Send.
- رسائل واتساب التلقائية وتأكيد التسليم الآلي تتطلب WhatsApp Business API.
- النسخة الاحتياطية الحالية لا تشمل سجل الطلبات.
